# PalindromeCheckerApp

### Use Case 8: Linked List-Based Palindrome Checker

This program checks whether a string is a palindrome using a **LinkedList**.  
Each character is added to the list, and the comparison is done from **both ends** using `removeFirst()` and `removeLast()`.  
LinkedList supports fast double‑ended operations, making this approach simple and symmetric.

## How to Run
```bash
javac com/palindromechecker/UseCaseEightPalindromeChecker.java
java com.palindromechecker.UseCaseEightPalindromeChecker
``
