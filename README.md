# PalindromeCheckerApp

### Use Case 4: Character Array-Based Palindrome Check

This program checks whether a string is a palindrome using a **character array** and the **two‑pointer technique**.  
It compares characters from the start and end of the array, moving inward until all characters match.

## How to Run
```bash
javac com/palindromechecker/UseCaseFourPalindromeChecker.java
java com.palindromechecker.UseCaseFourPalindromeChecker
