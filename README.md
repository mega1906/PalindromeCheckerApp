# PalindromeCheckerApp

### Use Case 5: Stack Based Palindrome Checker

This is a small Java program that checks whether a string is a palindrome using a **stack**.  
Characters are pushed onto the stack and then popped in reverse order to compare with the original string.

## How to Run
```bash
javac com/palindromechecker/UseCaseFivePalindromeChecker.java
java com.palindromechecker.UseCaseFivePalindromeChecker
