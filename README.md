# PalindromeCheckerApp

### Use Case 9: Recursive Palindrome Checker

This program checks whether a string is a palindrome using **recursion**.  
The comparison starts from both ends of the string and moves inward with each recursive call.  
The recursion stops when the characters do not match or when the pointers cross.

## How to Run
```bash
javac com/palindromechecker/UseCaseNinePalindromeChecker.java
java com.palindromechecker.UseCaseNinePalindromeChecker
