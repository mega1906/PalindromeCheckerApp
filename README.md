# PalindromeCheckerApp

### Use Case 10: Case-Insensitive & Space-Ignored Palindrome

This program checks whether a string is a palindrome **after normalizing it**.  
The normalization removes spaces and converts the string to lowercase so the validation is based on the actual characters, not formatting.

Example:  
`A man a plan a canal Panama` → becomes → `amanaplanacanalpanama`

## How to Run
```bash
javac com/palindromechecker/UseCaseTenPalindromeChecker.java
java com.palindromechecker.UseCaseTenPalindromeChecker
