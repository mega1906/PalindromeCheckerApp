# PalindromeCheckerApp

### Use Case 13: Performance Comparison

This program compares the execution time of two palindrome algorithms (**StackStrategy** and **DequeStrategy**) on the **same input**.  
It runs each strategy once, measures time using `System.nanoTime()`, and prints the results.

## How to Run
```bash
javac com/palindromechecker/UseCaseThirteenPalindromeChecker.java
java com.palindromechecker.UseCaseThirteenPalindromeChecker
