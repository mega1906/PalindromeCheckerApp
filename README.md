# PalindromeCheckerApp

### Use Case 2: Print a Hardcoded Palindrome Result

This program performs a simple palindrome check using direct character comparison.  
It reads a string from the user and compares characters from both ends of the string until the middle is reached.

## How to Run
```bash
javac com/palindromechecker/UseCaseTwoPalindromeChecker.java
java com.palindromechecker.UseCaseTwoPalindromeChecker
